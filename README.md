# Windows Helpdesk Lab
**About This Project**
This repository documents hands on IT support practice using Windows 11. It demonstrates beginner level troubleshooting, network diagnostics, technical documentation, and safe support procedures. This is to help me build practical skills for entry level IT helpdesk. 

# Projects
1.[Network Troubleshooting Lab](https://github.com/kittyarcade75/Windows-IT-Helpdesk-Lab/blob/main/Network-troubleshooting.md)

**Skills Practiced:** 
* Windows network configuration with command "ipconfig" in PowerShell
* IP connectivity testing with command "ping" in PowerShell
* DNS troubleshooting with command "nslookup" in PowerShell
* PowerShell network configuration checks
* Interpreting results and documenting findings

2.[Helpdesk Troubleshooting Guide](https://github.com/kittyarcade75/Windows-IT-Helpdesk-Lab/blob/main/Helpdesk-Troubleshooting-Guide.md)

**Scenarios Covered:**
* Diagnosing a reported internet connectivity problem
* Troubleshooting an application that will not open
* Handling a user sign in problem safety
* Recording findings and identifying when to escalate

**Lab Enviornment:**
* Operating system: Windows 11
* Memory: 16 GB Ram
* Tools: Windows Terminal, PowerShell, and built in Windows utilities

# Notes
this repository will contain personal learning exercises. Guides will only include scenarios. A separate file will be made including real practice. No passwords, verification codes, private networks, or IP addresses are included. This portfolio will continuously be expanded.
